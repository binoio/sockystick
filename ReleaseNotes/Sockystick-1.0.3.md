# Sockystick 1.0.3

Sockystick 1.0.3 brings a refreshed squircle-filling app icon and an option to hide the Dock icon, allowing Sockystick to run exclusively in the menu bar.

### What's New
- **Option for No Dock Icon**: Like Kona, you can now configure Sockystick to run exclusively from the macOS menu bar extra with the Dock icon hidden. Toggleable anytime in Settings > General > Appearance.
- **Updated App Icon**: The app icon now tightly fills the macOS squircle without borders or drop-shadow artifacts, featuring high-fidelity dark carbon mesh, glowing neon circuit traces, and an illuminated router proxy puck.
- **Seamless Window Activation**: Starting Sockystick with the Dock icon hidden stays discreetly in the menu bar, while selecting "Open Sockystick…" from the menu bar item brings the window forward smoothly.
