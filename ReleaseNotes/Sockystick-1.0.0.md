# Sockystick 1.0.0

Initial release of **Sockystick** — the macOS GUI Dock and Menubar app for toggling SOCKS5 proxies on active network interfaces.

### Features
- **One-Click Proxy Toggle**: Easily enable or disable SOCKS5 proxy status for your active network interface.
- **Dock & Menu Bar Modes**: Control proxy settings from the menu bar status item or the dedicated GUI window.
- **Interface Selection**: Automatically detects active default network interfaces (Wi-Fi, Ethernet) or select custom target interfaces.
- **Sparkle 2 Updates**: Automatic software update checks powered by Sparkle 2.
- **Apple Developer Notarized**: Signed and notarized with Hardened Runtime for macOS.
