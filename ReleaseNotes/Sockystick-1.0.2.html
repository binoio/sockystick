Sockystick 1.0.2

Sockystick 1.0.2 introduces automatic proxy teardown on application quit and brand new dynamic hockey stick menu bar icons.

  • Automatic Proxy Teardown on Quit: The system SOCKS5 proxy on active network interfaces is automatically disabled and the local authentication bridge is stopped whenever Sockystick terminates.
  • Dynamic Hockey Stick Menubar Icons: Custom vector icons showing a hockey stick when disconnected, and a hockey stick with a puck when connected and active.
  • Clean Menu Bar: Removed text labels for a minimalist, distraction-free menu bar presence.
  • Sparkle 2 Updates: EdDSA-signed automatic updates.
