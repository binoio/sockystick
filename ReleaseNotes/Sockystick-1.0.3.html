Sockystick 1.0.3

Sockystick 1.0.3 brings a refreshed squircle-filling app icon and an option to hide the Dock icon, allowing Sockystick to run exclusively in the menu bar.

  • Option for No Dock Icon: Configure Sockystick to run exclusively from the menu bar extra with the Dock icon hidden via Settings > General > Appearance.
  • Updated App Icon: High-fidelity icon tightly filling the macOS squircle without border or drop-shadow artifacts.
  • Seamless Window Activation: Starts quietly in the menu bar when the Dock icon is hidden, while opening windows from the menu bar brings them forward smoothly.
