Sockystick 1.0.1

Sockystick 1.0.1 introduces an updated 3D app icon, local SOCKS5 authentication bridging for seamless browser compatibility, and Sparkle 2 updates.

  • Brand New App Icon: A 3D-rendered composite carbon fiber hockey stick with braided ethernet cable tape, glowing circuit bus routing, and an illuminated proxy router puck.
  • Local SOCKS5 Auth Bridge: Transparent RFC 1929 authentication bridge enabling full authenticated SOCKS5 proxy support in Safari and system apps without OS limitations.
  • Framed Socket Streaming: Non-blocking byte buffering and direct TLS Client Hello forwarding for responsive web browsing.
  • Sparkle 2 Updates: EdDSA-signed automatic updates.
