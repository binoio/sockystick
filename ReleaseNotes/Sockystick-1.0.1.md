# Sockystick 1.0.1

Sockystick 1.0.1 introduces an updated 3D app icon, local SOCKS5 authentication bridging for seamless browser compatibility, and Sparkle 2 updates.

### What's New
- **Brand New App Icon**: A 3D-rendered composite carbon fiber hockey stick with braided ethernet cable tape, glowing circuit bus routing, and an illuminated proxy router puck designed to fill the macOS squircle.
- **Local SOCKS5 Auth Bridge**: Integrated transparent RFC 1929 authentication bridge enabling full SOCKS5 proxy authentication support across Safari, Firefox, and macOS system services without OS-level limitations.
- **Framed Socket Streaming**: Non-blocking byte buffering and direct TLS Client Hello packet forwarding for smooth, responsive web browsing.
- **Sparkle 2 Auto-Updates**: EdDSA-signed automatic update checking and delivery.
