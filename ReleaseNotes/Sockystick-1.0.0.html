Sockystick 1.0.0

Initial release of Sockystick — the macOS GUI Dock and Menubar app for toggling SOCKS5 proxies on active network interfaces.

  • One-Click Proxy Toggle: Quickly enable or disable SOCKS5 proxy settings on active network interfaces.
  • Dock & Menu Bar Modes: Full support for menubar control item and main application window.
  • Interface Auto-Detection: Automatically identifies the active primary connection (e.g. Wi-Fi en0).
  • Sparkle 2 Updates: Integrated automatic updates.
