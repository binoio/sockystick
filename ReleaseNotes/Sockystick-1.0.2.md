# Sockystick 1.0.2

Sockystick 1.0.2 introduces automatic proxy teardown on application quit and brand new dynamic hockey stick menu bar icons.

### What's New
- **Automatic Proxy Teardown on Quit**: The system SOCKS5 proxy on active network interfaces (Wi-Fi, Ethernet) is automatically disabled and the local authentication bridge is safely stopped whenever Sockystick is quit.
- **Dynamic Hockey Stick Menubar Icons**: Replaced legacy system network icons and text with elegant vector template icons:
  - **Disconnected**: Clean silhouette of a hockey stick.
  - **Connected & Active**: The hockey stick with a hockey puck on the ice ahead of the blade toe.
  - **Minimalist**: Removed "SOCKS" text label for a modern, distraction-free menu bar appearance.
- **Sparkle 2 Auto-Updates**: EdDSA-signed automatic update checking and delivery.
