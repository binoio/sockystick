# Sockystick 1.0.5

Sockystick 1.0.5 aligns the application icon with Apple's macOS Human Interface Guidelines icon grid and Dock proportions.

### What's New
- **Dock Icon Alignment**: Adjusted the icon layout to Apple's standard 824×824 pt squircle grid within the 1024×1024 pt canvas with standard optical padding and soft drop shadow, matching the size and proportions of all macOS system and third-party apps in the Dock.
